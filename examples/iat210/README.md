# IAT 210 example course starter

`IAT210-Fall2026-example-course-starter-v2.0.imscc` is a structured starting point from which a
production course may be developed. It demonstrates the Canvas materials produced and managed by
this toolkit.

## Status and limitations

- This course starter was generated with AI under the direction of M. Horrigan.
- It is not a production course and is not ready for teaching use.
- Import it only into a disposable, unpublished Canvas sandbox.
- Review its dates, policies, links, assignment settings, seven quiz shells, module organization,
  outcomes, rubrics, accessibility, and institutional requirements before adapting it.
- The quiz shells are placeholders. Each contains one demonstrative question rather than the ten
  reviewed questions specified by the draft course policy.
- The package contains exactly seven Practice Quizzes. It reflects the revised 4-5-4 project and
  module structure exported from the guarded sandbox on August 8, 2026.
- Unpublished outtake pages and the locally uploaded Trammell PDF were removed for distribution.
  The course starter uses the open-access publisher link for that reading.
- External links and names of third-party works remain subject to their respective owners' terms.
  Linked readings and media are not included.
