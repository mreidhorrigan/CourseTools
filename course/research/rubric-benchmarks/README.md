# Rubric endpoint benchmarks

These dossiers test whether course rubrics distinguish exemplary published games from demonstrably broken simulated submissions. Existing games are evaluated twice: against the complete course rubric and against its portable design criteria. The latter removes student-specific contribution evidence that cannot logically be supplied by a published game.

Run `scripts/mistral_rubric_discrimination.py`. Results and copies of every evaluated text are written under `out/course-development/mistral-discrimination/`. Model judgments are diagnostic and require human review.
